TL:DR; pipx, maestral, fresh-editor (IDE)

I like to write, which inevitably means I’ve been exploring tools for doing so.

Partly I write these blog posts (which are really a way to record commands my future self will need when I break something), partly bad fiction I’m never going to show to any living soul (it’s a way to calm down).

I’ve become kind of frustrated by the software one would normally use for this: MSWord and LibreOffice are big and pretend that you’re working on paper for some reason. I like using Markdown for stuff, but VSCode is overkill and fairly cluttered by default. I also want to be able to do this from either my Chromebook or from linux running on any one of the old rusty laptops and devices I seem to accumulate, so something lightweight and fast to load would be better. I need stuff I can use from the command line of the Linux container running on my Chromebook, because it’s the only computer I have light and portable enough I can carry it alongside my office laptop, but Android’s offering for editors either aren’t great or ARE great but don’t interface with Dropbox very well.

A final requirement for myself is that my writing be backed up to Dropbox (it’s not really worth anything but I’d be sad losing my ramblings) (yes, some people still use Dropbox).

Dropbox solution: Maestral

Maestral’s a great little find, a command-line only client for Dropbox that handles syncing with a pretty low memory and CPU use. It’s a python tool, so to install it, use pipx. Pipx lets you install python modules/programs into their own isolated environments, which then lets you use the tools you’ve installed systemwide. Handy!

sudo apt update
sudo apt install -y python3-pip python3-venv pipx  # Install pipx and dependencies
pipx install "maestral"                            # Install tool
pipx ensurepath                                    # Makes sure pipx installations are discoverable by your system

Authenticate Maestral

Running maestral start the first time will trigger the setup and authentication process, follow the instructions and once authenticated you can decide which folders to sync, which is handy if like me you have a terabyte of random old files archived that you’d rather leave behind.

To later add or remove new folders to list:

maestral excluded add/remove ...

(Though it’s easier to fire maestral --help and figure out anything you have to change from there).

Enable autostart of python daemon

maestral autostart -Y

(Works on OSX, Windows, and any Linux distro using systemd, which is the majority and definitely anything Debian derived).

Writers

A few options!

Zettlr - the full GUI app

Really good GUI markdown editor. Specifically intended for writing and publication from Markdown, rather than being a generic editor/IDE I’m repurposing. Downside: Uses Electron, so HEAVY. Can be installed after adding apt repo with sudo apt install zettlr as one would expect.

Instructions for adding the apt repo thingy, including handy scopy-paste commands, are here

Having now used it for a bit, I’m really quite taken with it when I’m on my Mac, it’s very clean, the file browser on the left is simple as I like. The shortcut for opening that file browser is quite annoying (CMD+! means finger gymnastics to get Shift too). There’s a spell-checker which is occasionally handy (I write enough technical stuff that spellcheckers are perpetually confused). It has a writing focus mode in which only the current paragraph or line is highlighted with everything else greyed out, but that mostly just distracts me as things go in and out of focus. I like things not to move or change unless I tell them to because I’m old and grumpy.

Fresh - terminal editor

I love that this exists. TUI based but with full support for a mouse so that I don’t have to learn weird keyboard shortcuts (navigating my editor has never been the thing that significantly slows my work). That said, it’s nice that I can open and close the file browser with CTRL+B, keeping my working document clear of GUI clutter, which was my main goal. This is meant to be a code editor so abusing it to write documents may seem a little odd, but having a full interface and syntax highlighting in a TUI but with clickable buttons and options is worth it, and by default there’s very little in the way of menus and clutter around the editor window!

It’s also very nippy, due to not bothering to power a GUI. I stuck it on the dark Dracula theme and never looked back. Install with brew install fresh-editor.

The only complaint I have is that the last line of the document is (of course) displayed right at the bottom of the screen. This makes sense, but I’m always in my head comparing it to Zettlr, which has some space padded out down there so that you aren’t staring at the absolute lowest part of your laptop screen. It’s a pretty niche complaint really.

Simple Markdown (an Honourable Mention for Android)

An honorable mention: This is a pretty… simple… markdown editor. All I wanted, this Android app works just fine. The only reason i couldn’t use it was that it didn’t sync with Dropbox. Using it on the Chromebook I could see files in Dropbox, including ones that had been set to available Offline, but clicking “save” for a location in Dropbox while offline would fail. This was really annoying and probably more Google’s fault than the makers of this app.

Joplin for notes

Not really about the writing part, I create a lot of throwaway notes in the process. Joplin is a markdown-based notes app that will sync using Dropbox, so my files stay on the service I want, and I can install it on Android, my Macbook, or just about anything else. This makes it handy mostly for writing down any ideas (writing or work related) as they happen. Because the blog system (Quarto, see below), my writing software and my notes are all Markdown of some flavour, it’s easy for work in one space to evolve into a more complete piece in another, straight copy-paste works fine.

I hear the cool kids use Obsidian, I’ve not tried it yet :)
