I did this on an M1 Macbook Air running OSX, adapt as you need :)

Install Ollama and get a model that can do code

I’m just using Ollama to host and serve open models for other applications. It can do a bit more, like install and set up Hermes with your models, for example.

To install, download from their downloads page, or copy and run their script to handle the whole process for you.

At the command line, type ollama help

Install Aider

Aider is a CLI tool for LLM powered coding, decribing itself as a CLI AI pair programming tool. It works fairly simply and neatly, called from the command line, within a repo, and creating commit messages for changes. The latter part is why it’s clean; a way to manage all the changes an AI might make is required, and git already exists. I also like that it doesn’t force any particular IDE on to me.

It is however a python tool and so requires a python environment. I don’t want to have to set the thing up for every project; I want my coding assistant tied to my laptop, not any particular codebase. To install Aider “universally”, I’m using pipx, a tool that installs python applications in their own isolated environments.

For convenience: pipx

To install pipx (assuming homebrew):

brew install pipx

Then for Aider, I need python 3.11, the latest that seems to carry all of the dependencies pipx requires:

brew install python@3.11

Installing with more recent versions of python gave me errors with setuptools (removed in python 3.14) and numpy (apparently Aider needs an old version).

I’d bet money there’s ways to get Aider working with more recent versions of python, but since the version supporting Aider is abstracted away by pipx anyway and can’t affect my projects, I don’t care. This works!

Installing Aider

Finally I get to install Aider:

pipx install --python python3.11 aider-chat

You make Ollama available to it using environment variables it knows to watch for:

export OLLAMA_API_BASE=http://127.0.0.1:11434 # local Ollama server endpoint defined

And then change the default Ollama context window length to something more reasonable:

export OLLAMA_CONTEXT_LENGTH=8192

(Ollama’s default context length is ~2k tokens I think, and truncates silently when you go over that. You can imagine the chaos.)

And of course I want these to be persistent on my laptop for me. Since I’m a pleb who just uses the Mac’s default zsh shell, I add the export lines to my ~/.zshrc file so that they’re run each time I log in.

Run Aider

Create a new folder for your project, or cd into one that exists. Start Aider in the terminal using:

aider --model ollama_chat/<model>

I’m using the gemma4:12B model as I write this, it runs on my M1 mac with 16GB ram but it’s slow, almost down to my talking speed, in generating tokens. In future I’m going to set this up with a model running on my desktop on the other side of my office (which can support much larger models, running faster). I’ll also try it out with some smaller models, see what kind of results I get.

I also need to test with the much larger context windows the Gemma and Qwen models will support.

React to files

For full details definitely read Aider’s own guidance. If you add the --watch-files flag, Aider will re-read saved files and react to specifically tagged comments in your code.

For example you could say:

def factorial(n) # Implement this. AI!

(this example, again, taken from their own guidance pages)

The other magic comment is AI? to ask a question.

I like this, because I can task the AI with making something in one file, while I go work in another. Matters more for people running local models slowly :P

So the command I actually run to start it is:

aider --model ollama_chat/gemma4:12B --watch-files

And I’d like to make this easy to do, so I’m adding an aliased command to my ~/.zshrc like so:

alias gemma='aider --model ollama_chat/gemma4:12B --watch-files --notifications'

That last additional flag, for notifications, enables notifications when Aider needs my input, figure it’ll be useful if I need to leave it running for a bit on longer jobs.
